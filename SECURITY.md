# Security

## Reporting

If you find a vulnerability in the contract or the site, please report it privately before public disclosure.

Open a private issue or contact the maintainer directly.

## Scope

- `contracts/HireWif.sol`
- Payment and approval flow in the frontend
- Result API

## Out of scope

- Third-party dependencies (wagmi, viem, Next.js)
- User wallet security
- Offchain agent behavior beyond the result endpoint

## Response

We aim to acknowledge reports within a few days and address confirmed issues promptly.
